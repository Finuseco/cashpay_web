Étape Suivante : Créer un Emplacement Publicitaire

Pour commencer à afficher des publicités, vous devez créer votre premier "emplacement". C'est la zone spécifique sur votre site où nos publicités apparaîtront.

  1. Rendez-vous sur votre tableau de bord éditeur.
  2. Cliquez sur "Créer un Emplacement".
  3. Donnez-lui un nom (ex: "Bannière Header") et choisissez le format.
  4. Copiez le code <iframe> fourni et collez-le à l'endroit désiré dans le code de votre site.
