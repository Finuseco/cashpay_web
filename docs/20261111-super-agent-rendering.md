# Réclamations : rendu et contrôles

La recherche des réclamations internationales accepte maintenant un nom ou une référence manquante. Les dates absentes ou invalides affichent un tiret au lieu de provoquer une exception de rendu. Le même traitement est appliqué aux dates des abonnements TV.

Le chargement invalide affiche une erreur ; les réclamations proposent une nouvelle tentative. Les réponses inter-agent sont contrôlées avant affichage. Un détail incomplet ne permet pas d’ouvrir le formulaire de règlement. Les champs textuels de l’audit ne rendent plus directement un objet JSON.

Les motifs de rejet utilisent RadioGroup. Le menu mobile est une navigation HTML repliable, sans menu déroulant en portail. Les autorisations, réservations de fonds et règlements serveur restent inchangés.

Vérifications : rendu React réel avec nom/référence nuls et dates invalides ; analyse de 47 fichiers accessibles depuis l’espace super-agent, sans Select natif, Select Radix ni DropdownMenu de formulaire restant. La compilation conserve des avertissements sur des imports et sources externes préexistants ; leur présence ne doit pas être confondue avec une recette sur le VPS.
